# GEB running glossary

Terms in the order they were first introduced. "01" = Introduction: A Musico-Logical Offering.

| Term | Plain meaning | First in |
|---|---|---|
| Strange Loop | Moving up (or down) through levels of a system and ending up back where you started | 01 |
| Theme | The main melody a piece of music is built from | 01 |
| Voice | One independent melodic line in a piece | 01 |
| Fugue | Voices enter one by one with the same theme, then weave together | 01 |
| Self-reference | Something that talks about, or points back to, itself | 01 |
| Chromatic | Moving one piano key at a time (black and white keys alike) | 01 |
| Canon | A theme played against a rule-bound copy of itself | 01 |
| Inversion / retrograde / augmentation | Copy upside-down / backwards / slowed to double length | 01 |
| Isomorphism | Two things whose parts and relationships line up one-to-one, so one can stand in for the other | 01 |
| Beat, bar | One pulse / a group of (here 4) beats | 01 |
| Interval, octave, fifth, semitone | Distance between notes / same note 12 keys up / 7 keys up / 1 key step | 01 |
| Key, modulation | A piece's home note and scale / moving from one key to another | 01 |
| Shepard tones | Notes played in many octaves at once so the octave is ambiguous | 01 |
| Hierarchy | A system arranged in levels, one above another | 01 |
| Tangled Hierarchy | A hierarchy whose levels loop into each other | 01 |
| Paradox | Reasoning where every step seems fine but the result contradicts itself | 01 |
| Proof, provable | Rule-following chain of steps from axioms / reachable by one | 01 |
| Formal system, axiom, theorem | Starting statements + mechanical rules / a starting statement / a derived statement | 01 |
| Consistent, complete | Never proves a contradiction / proves every true statement | 01 |
| Number theory | Mathematics of whole numbers 0, 1, 2, … | 01 |
| Prime | Number divisible only by 1 and itself | 01 |
| Gödel numbering | Coding each formula as a unique number | 01 |
| Incompleteness Theorem | Any consistent system strong enough for arithmetic has true but unprovable statements | 01 |
| Parallel postulate | Through a point beside a line there's exactly one line that never meets it | 01 |
| Set | A collection of things | 01 |
| Zeno's paradoxes | Ancient Greek puzzles, e.g. Achilles never catching a tortoise | 01 |
| Lithograph | A print made from a drawing on a flat stone or metal plate | 01 |
| Ricercar | Old name for a fugue (Italian, "to seek") | 01 |
| Clash | Two notes sounding together that grind against each other (here: 1, 2, 6, 10, 11 piano keys apart) | 01 |
