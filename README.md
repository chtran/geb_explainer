# GEB explainers

A chapter-by-chapter visual + audio companion to Douglas Hofstadter's *Gödel, Escher, Bach*.

Each chapter (or Dialogue) gets its own folder with a single self-contained `index.html` — open it in a browser.

| # | Section | Folder |
|---|---------|--------|
| 01 | Introduction: A Musico-Logical Offering | `01-introduction/` |

## Conventions (for future explainers)
- One self-contained HTML page per chapter: no build step, no external files except Google Fonts.
- Colour code: Gödel = blue `#2c5282`, Escher = green `#2f6b4f`, Bach = red `#9b2f2f`, highlights = gold `#b7862b`, on parchment `#f6f1e7`. Type: EB Garamond (body), Inter (UI), JetBrains Mono (code).
- No voice narration — audio is music demos only.
- Music is synthesized live with the Web Audio API.
- Every page ends with a one-breath recap and a short self-check quiz.
- Paraphrase the book — no long quotes.
